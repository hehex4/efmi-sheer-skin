# 步 11：实机验收 👁

## 目标

用实机确认透肉、外观切换、雨天水珠和雪天积雪都正确；异常时再用纯绿、范围或高光变量探针定位。

## 进入条件

- [ ] 步 10 的 zip 与工作区交付检查均通过。
- [ ] 新 ini 已通过完全重启加载，目标 ShaderFixes 标记文件已挪走。
- [ ] 主控角色处于用户确认的丝袜状态与目标视角。

## 操作

先判断是否为首次验收或重建基线。新 mod、新 PS/修补底子、游戏/RabbitFX 更新、无法解释的异常或缺少通过记录时，完成首次全部检查；工作区要求四道门则按第 6 项顺序执行，第 1–5 项只是操作细节，不再另跑一次。已有有效基线的后续改动按下表重验；其它工作区明确禁止复用时从其规则。

| 后续改动 | 本次实机检查 | 不必重复的有效基线结果 |
|---|---|---|
| 仅透肉/高光强度等参数，确认未动底子、采样、变量映射、范围及天气逻辑 | 正常外观与两档切换，看变化是否符合预期 | 纯绿、范围探针、N/L/V/T 探针与已通过的雨雪 |
| 改目标 draw、遮罩/UV 范围、状态分支 | 命中与范围（有歧义才用探针）、受影响状态外观与按键 | 未受影响的其它 draw；若影响天气作用范围则重验相应雨雪 |
| 换肤色贴图/重烘，shader 和天气通路未变 | 肤色、接缝、细节、受影响状态及视角 | 已通过的门控/探针；若改变染色或影响天气合成则重验相应天气 |
| 改高光变量映射、材质/雨雪逻辑，或出现异常 | 对应变量探针/灯光/天气及正常对照 | 仅复用确知未受影响的结果；依赖不明时回首次检查 |

“复用”须有同一基线的实际通过记录与可核对的改动；不能用“以前应该测过”代替。只在光照/天气条件出现时才暴露的缺陷，仍需相应检查。首次雨雪未测则保持该项待验；后续无关参数调整无需为了结案重新等待天气。

1. 首次验收看三类项目；后续只执行上表要求的部分：

   - 透肉：正对镜头能透出肤色，轮廓接近袜色；无黑块、紫块、闪烁。
   - 外观键：按 `<外观键>` 能在“只透肉 / 透肉 + 各向异性高光”两档切换；重新进游戏默认回 0。
   - 天气：在雨天看一次目标丝袜有水珠，在雪天核对目标部位的落雪；改过丝袜布料落雪时，丝袜脚背应有雪、光腿不应因此积雪。晴天结果不能代替这两次。

2. 透肉完全没出现或范围不确定时，编辑 `<现役mod ini>`，把 `global $sheer_debug_<mod标识> = 0` 改成 1，保存并完全重启游戏。该开关会让本次替换范围整块纯绿。拍 `<检查截图>`，按 VP5a 判定；看完立刻改回 0 并再次完全重启。

3. 正式效果按 VP5b 核对；已有清楚的用户实机反馈即可记录，不为填写固定 JSON 再索要同一组截图。需要定位细节、反馈含糊或互相矛盾时才补 `<正式截图>`。VP5a 只在实际触发检查开关时使用，主模型能看就不重复委派视觉复核。

4. 纯绿范围过大或袜子与身体共 draw 时，才把 `<正式HLSL>` 顶部 `ANISO_DEBUG_MODE` 临时改为 7，保存后游戏内按 F10；结合 `<范围框>` 核对范围。修正框、重建正式 PS 后把模式改回 0。

5. 只有“透肉正常但高光位置/移动异常”时，才依次使用高光变量探针 2 → 3 → 4 → 5；只看对应变量，不在这些档调强度。结束后把模式改回 0。

6. 工作区规定“检查开关 → 范围探针 → 正常对照 → 雨雪”时，严格按此顺序：Gate 1 把 INI 检查开关置 1 确认纯绿命中；Gate 2 把检查开关恢复 0，用模式 7 核对用户选定范围；Gate 3 恢复模式 0，比较正式透肉、袜色/肤色及两档按键；Gate 4 在雨天、雪天分别核对目标部位。前一道失败就停在该门修复。其它工作区明文规定的门序按其原文执行。[ingame-gates.md](ingame-gates.md) 是借用高光排障参考，不能用其 N/L/V/T/H 或夸张橙色探针取代工作区的范围、普通对照和雨雪门。

7. 完成后确认 `<现役mod ini>` 的检查开关为 0、`<正式HLSL>` 的 `ANISO_DEBUG_MODE` 为 0，再记录工作区要求的实机结果。

## 期望输出

本步没有脚本 stdout。以下是观察记录结构示例，不是本案取证：

```text
透肉：正对（有/无），轮廓（袜色/异常），黑紫块或闪烁（有/无）
外观键：第 0 档（只透肉/异常），第 1 档（透肉+高光/异常）
雨天：水珠（有/无）
雪天：积雪（有/无）
检查开关：目标范围（纯绿/未绿），其他部位（正常/变绿）
收尾：sheer_debug=0，ANISO_DEBUG_MODE=0
```

## 判定

| 看到什么 | 结论 | 下一步 |
|---|---|---|
| 透肉、两档切换、雨天水珠与雪天积雪全部正确 | 默认实机验收通过 | 按工作区结案 |
| 检查模式丝袜整块纯绿，其他部位正常 | 接线与目标 draw 命中 | 改回 0，按 VP5b 查参数/肤色 |
| 丝袜画在身体贴图上，检查模式整块身体都绿 | 替换 draw 本来就是整个身体，绿色显示的是替换范围 | 用模式 7 与 VP1/当前 `<范围框>` 确认袜区；正式档靠遮罩/框限制效果 |
| 独立丝袜网格却连身体或饰件一起绿 | draw 或范围锁错 | 回步 01/02 核对几何与用户范围，再回步 06/07 |
| 检查模式不绿 | 替换未触发 | 回步 03 查双门控与 ShaderFixes，回步 09 查 `run` 和路径 |
| 正对不透、轮廓不实或颜色错 | 参数或肤色来源错误 | 按 VP5b 回步 06/07；每次只改一个参数 |
| 有黑块、紫块或游动条纹 | 槽位、寄存器、cb 或签名错误 | 回步 05/08 查覆写与反射 |
| 晴天正常，雨天无水珠或雪天无积雪 | E6/E6c/E7 或落雪布料公式错误 | 回步 04 对照 msasm 回环，再核步 07 的现场落雪映射 |
| 透肉正常，高光不随光或镜头移动 | 高光变量映射错误 | 只跑模式 2–5，回步 05 修 N/L/V/T |

## 失败处理

| 症状 | 原因 | 修法 |
|---|---|---|
| 改检查开关后 F10 仍没变化 | ini 变量不由 F10 重新解析 | 完全退出游戏再启动 |
| 模式 7 一直留在画面 | HLSL 未改回 0 或 F10 编译失败 | 改回 0，查看 3DMigoto 红字后再按 F10 |
| 外观键同时触发别的功能 | 全局键冲突 | 回步 09 搜 Mods 与 `d3dx.ini`，换空键 |
| 本次需要验证雨雪但环境难以重现 | 本项待验 | 不声称本项通过；若仅无关参数改动且已有有效雨雪基线，则复用已有结果，不重新等待 |
| 视觉 JSON 缺字段或非法 | 视觉协议返回不合格 | 按 [vision-subagent.md](vision-subagent.md) 重问一次，再交用户手工回答 |
