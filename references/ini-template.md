# INI 接线入口

唯一可执行接线模板是 [步 09：INI 接线](step-09-ini.md)。先从步 03 取得现场门控，保留原 draw 的完整命令，再按步 09 接入所有用户选定状态和默认高光切换。不要从案例拼装第二套模板。

## 历史例子（只作原理证据，不可复制为当前配置）

2026-09 案例曾使用 VS 202 / PS 1718.1 和 instanced draw。这些值与 draw 类型只描述当时输入；当前门控、原 draw、槽位和在场变量必须分别从当前分类器、INI 与 PS 读取。

两个门控都需要：仅限制材质 PS 标签会把替换套到其它 pass。门控失败及未选状态分别回退原 draw；原命令可能是 indexed 或 instanced，操作名和参数都要完整保留。
