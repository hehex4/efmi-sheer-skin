# 透肉参数、配方与对照锚点

## 1. 参数与公式的对应

| 参数 | 公式里 | 效果 |
|---|---|---|
| `SHEER_ALPHA` | `t = saturate(ALPHA + 1 − OFFSET)`,指数 `2t` | 越大越透;主要改「中间透光区有多宽」 |
| `SHEER_W_MIN` | `w` 的下限(正对镜头) | 抬它 = 正面至少保留这么多织物 = 正面更黑 |
| `SHEER_W_MAX` | `w` 的上限(掠射) | 轮廓有多「实」;真丝袜斜着看丝线叠得最厚,所以轮廓最黑 |
| `SHEER_GAIN` | `final = lerp(原色, base, GAIN × 遮罩)` | 透肉总量;字面意思「保留多少原来的袜色」 |
| `SHEER_SPEC_GAIN` | 高光混合权重 | 0 = 关高光(编译器会整段剔除) |
| `SHEER_SPEC_COUPLING` | 高光 × `lerp(1, 覆盖率, COUPLING)` | 1 = 透出皮肤的地方亮带变弱(皮肤上没有丝线反光) |
| `SHEER_ALPHA_OFFSET` | Last Rite `cb6[17].w` | 固定 1.0,别动 |

透肉**先于**高光算:光先穿过纤维间隙透出肤色,再在纤维表面反射。

## 2. 为什么黑丝要把 W_MIN 抬得很高

混合在**线性光**里做,而人眼对暗部很敏感。线性 50% 的亮度在屏幕上是 sRGB 188 / 255,并不是「一半黑」。
所以只要混进 28% 的皮肤,屏幕上就已经有光腿一半多亮;照 Last Rite 原值(W_MIN 0,正对镜头约九成皮肤),
黑丝会被「透成白的」—— 2026-09-10 庄方仪案用户原话「加了这个白丝的透肉效果后让黑丝白了」。

## 3. 可见度与前提

透肉能表现的改变量 = `|肤色 − 袜色| × (1 − w) × GAIN`。

| 袜子 | 与肤色的差 | 结果 |
|---|---|---|
| 黑丝(last rite 76/64/66 vs 255/207/198) | 很大 | 效果最强,也最容易透成白的 |
| 白丝(255/239/239 vs 255/207/198) | 只有 G/B 三四十级 | 柔和的一层粉,正是实机截图里膝盖的样子 |
| 肉色丝袜 | ≈ 0 | **看不出来**,质感改靠光泽 / 织纹 |

另两个前提:肤色必须是**该模型自己的**(常数量它自己的皮肤图,或光腿贴图),以及分得出哪里是袜子。

## 4. 配方表(离线未打光反照率,sRGB;括号 = 皮肤份额)

光照对光腿和丝袜同比例,所以相对关系在游戏里成立;最终以用户眼睛为准。`scripts/sheer_param_table.py` 可复算任何组合。

**庄方仪黑丝**(肤色 227/206/193,袜 66/54/48):

| ALPHA / W_MIN / W_MAX / GAIN | 正对镜头 | 斜 60° | 接近轮廓 | 正对 ÷ 光腿 |
|---|---|---|---|---|
| 0.45 / 0 / 0.9 / 1 | 221/201/188 (94%) | 168/152/142 (47%) | 127/113/105 (22%) | **0.97 = 透白了** |
| 0.45 / 0 / 0.9 / 0.4 | 154/138/129 (38%) | 121/107/99 (19%) | 96/84/77 (9%) | 0.68 |
| 0.45 / 0.6 / 1.0 / 1 | 153/138/128 (37%) | 116/102/95 (17%) | 86/74/68 (5%) | 0.67 |
| 0.45 / 0.7 / 1.0 / 1 | 138/123/115 (28%) | 106/93/86 (12%) | 82/70/63 (4%) | 0.61 |

**last rite**(肤色 255/207/198):黑丝(袜 76/64/66)`0.45 / 0.65 / 1.0 / 1` ⇒ 正对 ÷ 光腿 0.65 / 0.65 / 0.65;
白丝(袜 255/239/239)`0.25 / 0 / 0.9 / 1` ⇒ 1.00 / 1.03 / 1.05。

同一个正对亮度,「降 GAIN」与「抬 W_MIN + W_MAX = 1」的区别在轮廓:后者轮廓更接近全黑,「中间透、边上黑」的丝袜感更强;
前者一个旋钮,但轮廓会留一点肤色。

## 5. 对照锚点(作者 2026-09 对 5 个现役丝袜 mod 贴图的横向测量;mod 更新后数字可能变,只作量级参考)

| 类型 | 「有袜 ÷ 光腿」sRGB 三通道比 | 特征 |
|---|---|---|
| 深色袜(perlica / xaihi) | 0.746 / 0.60–0.68 | 三通道近似相等 = 等比衰减(色相不变) |
| 浅色袜(tangtang) | 0.965 / 1.034 / 1.069 | 不等比、方向相反 = 去饱和(粉色被洗掉) |
| 袜口 / 加固 | 0.42–0.47,混向固定色 | 真实贴图常单独处理;着色器版会按丝袜一样透,视效果决定要不要单独遮 |
| 用户实调(last rite 黑丝,着色器版,2026-09) | 0.49 / 0.50 / 0.51(ALPHA 0.30、W_MIN 0.80、W_MAX 0.90、GAIN 0.8) | 比现役贴图 mod 更不透 ⇒ `suggest_sheer_params.py` 深色默认目标取 0.60(对照区间的偏暗端),不取中间 |

## 6. 调参手法

0. 默认值:`scripts/suggest_sheer_params.py` 按贴图给(深色袜解到正对 0.60、浅色袜用 Last Rite 原值、中间色两套之间过渡),
   装好后告诉用户参数在哪、每个量往哪调是什么效果;用户说「再透一点 / 太白了」再按下面的顺序改。
1. 参数段放在替换 PS 文件**最顶上**,改完保存 → 游戏里 F10(只改 hlsl 不用重启)。
2. 按状态一份文件;同一状态多片(小腿 / 大腿)各一份时,顶部参数段用同步脚本抄一致;想要不同就故意不同步。
3. 顺序:W_MAX → W_MIN → ALPHA,每次只动一个,步长 0.05;每次同机位同时间截图对比。
4. 调出满意的数就留在装机 hlsl 顶部的参数段里,那就是唯一记录(不另写文档);以后重新生成前,先把用户手调的值抄回 hlsl 头部那条重建命令的 `--state`,否则会被出厂值覆盖。
