## 3. 实机常量(2026-09-10 探针抓帧:LOD0 call 88;LOD1 只有 [16] 差 0.004)

```
cb6[ 6] = 1.000000 0.714593 0.620916 1.0   染色(暖色,乘在皮肤图集上)
cb6[ 2] = 0 0 0 0                          不输出 alpha,走不透明管线
cb6[15] = 1.000000 1.000000 1.000000 1.0   透出色乘子(干)= 白 ⇒ 透出的就是 diffuse × cb6[6]
cb6[16] = 0.765196 0.968637 1.000000 1.0   透出色乘子(湿)偏蓝
cb6[17] = 0.462361 0.415782 0.430988 1.0   xyz 织物 / 边缘色 = 中灰(线性 0.46 ≈ sRGB 180);w = 1.0 = alpha 偏移
cb6[18] = 0.175600 0.000000 1.000000 0.0   .w = 0 织物权重下限
cb6[19] = 0.900000 0.000000 0.220000 0.0   .x = 0.9 织物权重上限;.w = 0 ⇒ 额外图分支关
cb6[20] = 0.390000 0.500000 0.000000 0.0   分支 B 的后续项(未搬)
```

**方向(实机定死)**:`cb6[17].w = 1` ⇒ `t = alpha` ⇒ **alpha 越大越透**。正对镜头 `f = 0.05^(2a)`,`w = 0.9·f`:
a = 1 ⇒ w ≈ 0.002(几乎纯皮肤);a = 0.25 ⇒ w ≈ 0.20;a = 0.15 ⇒ w ≈ 0.37;a → 0 ⇒ w = 0.9(灰织物)。
白纱岛的 diffuse.a 多在 0.1–0.3、胸口最透处接近 1 ⇒ 典型 ≈ 八成皮肤两成织物。

**关键差别**:Last Rite 的 t15 是**皮肤图集**(hash `794a9d58`,与手部槽同一张)⇒ 它透出的就是 diffuse × 染色 = 皮肤。
丝袜的 diffuse 是袜子 ⇒ 移植时必须拆成「透出色 = 肤色 / 织物色 = 丝袜 diffuse」,常量做成 `SHEER_ALPHA / W_MIN / W_MAX` 旋钮。

## 4. 为什么不把整份白纱 PS 搬到丝袜上(路线 B,已查证、未执行)

着色器不是能单独拆下来装到别处的零件,它和「谁喂数据、数据放在哪个格子」绑死:

1. **VS → PS 插值契约对不上**:白纱 PS 要 TEXCOORD7 xyzw、TEXCOORD8 float xyz、TEXCOORD9 uint(材质号);
   布料 VS(`1479b2b5`)只有 TEXCOORD7 xyz、TEXCOORD8 uint,**没有 TEXCOORD9** ⇒ PS 拿未定义值去做 `cb2[...]` 动态索引
   (与「只门控 ps == 1718.1」卡死同类事故)。
2. **换成皮肤 VS 也不行**:皮肤 VS 顶点输入多一个 TEXCOORD7,权重 / 骨骼索引落在 v8/v9(布料在 v7/v8);
   游戏为丝袜切片建的 InputLayout 按布料 VS 编排 ⇒ 蒙皮全错 = 爆模。3DMigoto 没有命令能换 InputLayout。
3. **贴图槽随着色器变体漂移**:白纱 PS 的 t12→丝袜 draw 的 t13 … t20→t22 共 9 处重编号,还缺白纱专属 LUT `t10`;
   任何一处错都表现为「读到别的贴图」,静态检查查不出。
4. `cb6[15..20]` 是白纱自己的数,要全部常量化;还有几段(天气覆盖 r4.z、r9.w、1415–1418 进高光的项)没追完。
5. 丢掉目标部件原有的效果(比如各向异性高光)。

`docs/superpowers/plans/2026-09-10-zhuangfangyi-siwa-sheer-lastrite-ab.md` §0 与附录 B(非必读)。

## 5. 提取时的 hunting 教训

1. 离线按「独立混合状态 + 画得最晚 + 无描边」推出的 `19d3babe` / `0e81dd4f`(PS `7b942d49`)是别的半透明件,不是白纱。
2. mark 到的第一个让部件消失的 PS 可能是 prepass(`816908364e93e433`):skip 模式下 prepass 和材质都会让部件消失。
   认材质 PS 要看 VS(202 = `c6e55aaa` / `1479b2b5` 家族),或看「谁跟着一起消失」(材质 PS 只带同材质部件;prepass 带一大片小件和别的角色),
   或看导出大小(材质 PS asm 约 90 KB,prepass 约 6 KB)。
3. 被 ShaderRegex 打过补丁的 PS,mark 只导出补丁后 asm `<hash>-ps.txt`(首行 `MANUALLY DUMPED [ShaderRegex\...]`),
   不出 `_replace.txt`,与 ShaderCache bin 的反汇编逐指令相同 ⇒ 两条路线等价,mark 拿不到原版。
4. mark 之后 `ShaderFixes\` 必须清空 —— 留在那里的文件会被当成替换着色器加载。
5. 一个整装 mod 的 IBSkip 列表 = LOD0 + LOD1 成对,按「哪些帧里 LOD0 段在场 / LOD1 段在场」共现即可配对。
